## 指标的实际含义

- 整机 CPU 是短时双采样；容器 CPU 使用 docker stats 的采样窗口，按逻辑 CPU 数归一。二者采样窗口不完全一致，不能把同一屏上的数值当作严格同时刻的成本分摊。
- 进程内存为 RSS 汇总估算，多个进程可能共享内存；容器内存采用 Docker 报告值。公共服务只有明确属于同一 Compose 项目时才并入该项目。
- 只识别当前运行、账号可见的容器和常见应用进程。已停止的容器、任意脚本、其他 Web 服务器以及更复杂的代理链需要进一步适配或人工关联。
- 采集结果均有时间戳。失败时显示上次快照与错误，未获取的数据不填 0，不用随机值补齐。
- 自动发现按目录 / Compose 归组，确认后的名称、链接、备注单独保存。手工指标明确标注来源，清空手工值后恢复自动采集。
- RDAP 只保存域名、注册商、到期时间、查询时间和来源地址，不保存注册人联系方式；不向登记接口发送 SSH 凭据。www 入口复用对应域名记录，其他复杂子域名可能仍需人工确认根域名。
