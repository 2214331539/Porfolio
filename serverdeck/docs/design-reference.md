# 界面参考与实现

2026-10-16 查看了 [Mercury 官网](https://mercury.com/) 和 [公开产品演示](https://demo.mercury.com/dashboard)，并通过浏览器检查公开 HTML、字体与计算后的样式。

官网当前使用深色背景 `#171721`、灰白文字 `#ededf3`、主操作蓝色 `#5266eb`，搭配适度圆角和简洁的字体层级；产品演示使用更紧凑的工具条、对齐的数据列和渐进展开的明细。

本次采用官网的深色基调，以及产品演示的信息密度与明细表排版。保留单页：顶部服务器卡片，底部所选服务器的指标与项目。去掉原来的章节编号、英文口号、衬线标题与过小的正文。蓝色用于主按钮、选中边框和可操作的链接。

- 卡片采用原创 CSS 机架示意，弱光活动灯只是装饰，连接状态由实际采集结果决定。
- 桌面连接浮层；窄屏底部浮层和可横向滑动的服务器卡片。选中卡片自动出现在可见范围。
- 指标只用真实数值和容量条，不生成虚构的历史曲线。
- 原有密码遮罩、复制、项目编辑、服务展开与数据来源说明保留。
- 键盘可打开和关闭浮层、循环访问操作；系统减少动态效果设置会停用动画。

检索 MercuryTechnologies 的公开仓库时，未找到官网或银行产品 UI 的官方开源仓库。本项目没有复制它的品牌图标、专有 Arcadia 字体、摄影素材或打包脚本；组件、CSS 与机架示意均在本仓库实现。正文使用本地打包的开源 Hanken Grotesk，IP 与命令使用 IBM Plex Mono，中文使用设备字体。

主要源码：`src/App.tsx`、`src/ServerCard.tsx`、`src/ServerDetail.tsx`、`src/ui.tsx`、`src/styles.css`。
