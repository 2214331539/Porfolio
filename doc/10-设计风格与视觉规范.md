# 设计风格与视觉规范

本文件定义 PanOS 个人站的视觉语言与设计系统，是前端落地视觉的唯一基准。所有色值、字号、圆角、阴影、动效参数都应来自这里，并最终固化到 `apps/web/src/styles/tokens.css`（见 `05-前端结构.md`）。

**设计方向：淡色编辑极简 + 便当网格（Light Editorial Minimal + Bento）。** 近白底、大留白、克制的单一强调色、模块化大小卡片拼贴；衬线展示标题 + 无衬线正文营造编辑气质。整体淡雅、清爽、有呼吸感，但不走暖萌"治愈系"。

## 1. 设计定位

| 维度 | 取向 |
| --- | --- |
| 气质关键词 | 淡雅、克制、编辑感、通透、留白 |
| 视觉记忆点 | 衬线大标题 + 便当网格 + 极淡的分区色 + 细腻分隔线 |
| 情绪基调 | 冷暖中性的近白背景，黑墨文字，少量低饱和点睛色 |
| 前台 vs 后台 | 前台重排版与留白；后台同一套淡色 token，提升信息密度、收敛装饰 |

设计三条铁律：

1. **以白为主、以墨为骨**：背景近白、文字近黑，结构靠留白和细线，不靠大色块。
2. **强调色极少量**：单一强调色只用于链接、主 CTA、当前态；分区用极淡的 pastel 底色区分，不抢视线。
3. **排版即设计**：层级、对齐、间距是主要表现手段；动效轻微，服务于阅读节奏，且可被 `prefers-reduced-motion` 关闭。

## 2. 色彩系统

颜色全部以 CSS 变量承载。**以 Light 为主基调**，Dark 作为可选项保留（前台、后台均覆盖）。下方为基准值，实现时可微调但需保持对比度达标（§8）。

### 2.1 中性与背景（主骨架）

| 角色 | Token | Light | Dark |
| --- | --- | --- | --- |
| 页面背景 | `--color-bg` | `#F7F7F4`（暖调近白） | `#15171A` |
| 卡片/面板 | `--color-surface` | `#FFFFFF` | `#1C1F23` |
| 次级面 | `--color-surface-muted` | `#F1F1EC` | `#23262B` |
| 正文文字 | `--color-text` | `#1B1D1F`（墨黑） | `#ECEDEE` |
| 次要文字 | `--color-muted` | `#6B7075` | `#9BA1A8` |
| 弱化文字 | `--color-subtle` | `#9AA0A6` | `#6B7178` |
| 分隔线 | `--color-border` | `#E7E7E1` | `#2A2E34` |

### 2.2 强调色（极少量使用）

| 角色 | Token | Light | Dark | 用途 |
| --- | --- | --- | --- | --- |
| 主强调 | `--color-primary` | `#4F60E6`（柔和墨蓝） | `#7C8AF0` | 链接、主 CTA、当前态 |
| 主强调底上文字 | `--color-on-primary` | `#FFFFFF` | `#15171A` | 强调底上的文字 |
| 强调-淡底 | `--color-primary-soft` | `#EAEDFD` | `#23284A` | hover 背景、选中底 |

### 2.3 分区 pastel 淡色（便当卡背景）

极淡、低饱和，用于区分博客 / 图文 / 简历等分区，营造淡色调层次而不喧闹。

| 分区 | Token | Light 底 | 配套文字 |
| --- | --- | --- | --- |
| 博客 | `--tint-blog` | `#EAF0FF` | `#33406B` |
| 图文 | `--tint-notes` | `#FCEEE8` | `#6B4636` |
| 简历 | `--tint-resume` | `#EAF4ED` | `#2F5740` |
| 高亮/精选 | `--tint-highlight` | `#FBF3DA` | `#6B5A2A` |

### 2.4 语义色

| 角色 | Token | Light | Dark |
| --- | --- | --- | --- |
| 成功 | `--color-success` | `#3A9E6E` | `#4FC089` |
| 警告 | `--color-warning` | `#C7891F` | `#E0A845` |
| 危险 | `--color-danger` | `#CF4B4B` | `#E86A6A` |
| 信息 | `--color-info` | `#3B7FC4` | `#5BA3E0` |

后台 `StatusBadge` 映射：草稿=muted、定时=info、已发布=success、归档=warning、回收站=danger。

## 3. 字体系统

衬线展示体塑造编辑气质，无衬线正文保证可读，等宽用于代码。

| 角色 | Token | 字体栈（建议） |
| --- | --- | --- |
| 展示/大标题 | `--font-display` | `"Instrument Serif", "Noto Serif SC", Georgia, serif` |
| 正文/UI | `--font-sans` | `"Inter", "HarmonyOS Sans SC", -apple-system, sans-serif` |
| 代码 | `--font-mono` | `"JetBrains Mono", "Fira Code", monospace` |

字号阶梯（rem，基准 16px）：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--text-xs` | 0.75 | 标签、辅助 |
| `--text-sm` | 0.875 | 次要文字、表格 |
| `--text-base` | 1 | 正文 |
| `--text-lg` | 1.125 | 引导文案 |
| `--text-xl` | 1.5 | 卡片标题 |
| `--text-2xl` | 2 | 区块标题 |
| `--text-3xl` | 3 | 页面主标题 |
| `--text-hero` | clamp(3rem, 7vw, 5.5rem) | Hero 主标题（衬线） |

正文行高 1.7、标题 1.15；衬线大标题可加 `letter-spacing: -0.01em`，正文中文不加字距。

## 4. 间距、圆角、阴影、层级

### 4.1 间距（8pt 栅格）

```text
--space-1: 4px   --space-2: 8px   --space-3: 12px  --space-4: 16px
--space-5: 24px  --space-6: 32px  --space-8: 48px  --space-10: 64px  --space-12: 96px
```

区块纵向间距桌面 `--space-12`、移动 `--space-8`；卡片内边距 `--space-5`。

### 4.2 圆角

```text
--radius-sm: 8px     /* 标签、输入框 */
--radius-md: 12px    /* 按钮 */
--radius-lg: 16px    /* 便当卡（默认） */
--radius-xl: 24px    /* 大封面卡、弹层 */
--radius-full: 999px /* 头像、胶囊标签 */
```

淡色风偏大圆角更显柔和；卡片统一 16px。

### 4.3 阴影（极轻，淡色风靠分隔线而非重阴影）

```text
--shadow-xs: 0 1px 2px rgba(20,22,26,0.04);
--shadow-soft: 0 2px 10px rgba(20,22,26,0.05);
--shadow-card: 0 6px 24px rgba(20,22,26,0.06);
--shadow-float: 0 14px 40px rgba(20,22,26,0.10);  /* hover 抬升 */
```

卡片默认可仅用 `1px` 边框 + `--shadow-xs`，hover 再升到 `--shadow-card`。暗色下改用极弱外发光。

### 4.4 层级（z-index）

```text
--z-base:0  --z-raised:10  --z-sticky:100（导航）  --z-overlay:1000  --z-modal:1100  --z-toast:1200
```

## 5. 便当网格（Bento）规范

首页与部分聚合页采用便当网格：不同尺寸卡片在固定栅格内拼贴。

- 桌面 12 列栅格，`gap: var(--space-4)`；卡片跨列形成大小错落（如 Hero 占 7 列、简历占 5 列、图文 2×3 列）。
- 卡片基底：`--color-surface` + `1px` `--color-border` + `--radius-lg`；分区卡可用 §2.3 pastel 底。
- 卡片只承载一类内容（一段 Hero、一篇精选、一组图文），不堆叠过多信息。
- 移动端坍缩为单列，保持顺序：Hero → 简历摘要 → 博客 → 图文。

```text
┌───────────────┬───────────┐
│   HERO (7)    │ resume(5) │
│   serif title ├─────┬─────┤
├───────┬───────┤note │note │
│blog(4)│blog(4)│ (2) │ (2) │
└───────┴───────┴─────┴─────┘
```

## 6. 动效规范

轻微、克制，基于 Framer Motion。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、展开 |
| `--dur-fast` | 150ms | hover、按钮反馈 |
| `--dur-base` | 300ms | 卡片、弹层 |
| `--dur-slow` | 600ms | 区块入场 |

约定：

- **入场**：进入视口位移 12–20px + 透明度 0→1，列表元素 60ms 错峰。
- **hover**：卡片上浮 2–4px、阴影升至 `--shadow-card`、封面图缓放 1.02。
- **可访问性**：`prefers-reduced-motion: reduce` 下全部退化为淡入或无动画。

## 7. 关键场景视觉规范

### 7.1 首屏 Hero（淡色版）

不再以 3D 云海为默认。首屏 = 近白背景 + 衬线大标题（`--text-hero`）+ 一行墨色 Slogan + 主 CTA（`--color-primary`），右侧/下方衔接便当网格。3D/插画作为**可选增强**放进便当中的一个大格子，而非全屏铺底；低性能设备直接省略。

### 7.2 卡片体系

| 卡片 | 比例/特征 |
| --- | --- |
| 博客大封面卡 | 跨多列，16:9 封面 + 衬线标题 + 分类标签 |
| 博客标准卡 | 4:3 封面 + 标题 + 时间 |
| 图文竖卡 | 3:4，圆角 `--radius-lg`，图占 ~80%，底部短标题 + 点赞 |
| 简历摘要卡 | pastel `--tint-resume` 底，头像 + 一句话 + 技能胶囊 |

### 7.3 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `--color-primary` 底 + `--color-on-primary` 文字，`--radius-md` |
| 次按钮 | `--color-surface` 底 + `--color-border` 描边 |
| 文字按钮 | 仅文字，hover 下划线滑入 |

所有交互元素覆盖 `hover / focus-visible / active / disabled / loading` 五态。

## 8. 暗色模式与可访问性

- 暗色为可选项，前台后台均覆盖，由 `theme-store` 控制并写 `localStorage`，首屏读 `prefers-color-scheme`。
- 正文/背景对比度 ≥ 4.5:1，大标题 ≥ 3:1（WCAG AA）。pastel 分区底上的文字需用 §2.3 指定的配套深色。
- 图标按钮带 `aria-label`；焦点态用 `--color-primary` 外环，不只靠颜色区分状态；图片提供 `alt`。

## 9. 响应式断点

```text
sm:640  md:768  lg:1024  xl:1280  2xl:1536
```

- 便当网格：`< md` 单列，`md` 6 列，`lg+` 12 列。
- 博客列表：移动单列，`md` 两列，`lg+` 三列；图文瀑布流移动单列、桌面双列错位。
- Hero 标题用 `clamp()` 自适应。

## 10. 落地与交付

1. 本文件 token 全量落到 `apps/web/src/styles/tokens.css`，light/dark 各一套，Tailwind 通过配置引用 CSS 变量。
2. 组件一律消费 token，禁止写死色值/字号/圆角/阴影。
3. 设计变更先改本文件、再改 `tokens.css`，保持单一来源（与 `09-质量安全与运维.md` §10 一致）。
4. 建议沉淀内部 Style Guide 预览页或 Storybook 校验 token 与组件态。
