# 小潘同学产品文档

## 一、产品定位

“小潘同学”是一个个人内容站：前台让访客快速了解站点主人、按主题或时间阅读长期文章、浏览图文和作品、查看简历；后台让站点主人用最少的步骤写作和整理内容。设计上坚持信息分层：每一屏只讲一件事，更多内容收进标签页、折叠问答、悬停卡片等下一层，访客按兴趣逐层展开，不把所有信息堆在同一个视图里。

## 二、整体结构

前台一级入口为首页、文章、图文、作品、信息源泉、关于，做成顶栏里的一排胶囊，当前页为黑色胶囊；右侧是搜索框和深浅色切换。全站任意页面也可以按 Ctrl+K（或 `/`）打开搜索，界面上不显示快捷键提示。后台按任务分组：总览；内容（文章、图文）；展示（作品集、信息源泉、简历）；系统（站点设置、服务器）。仓库不再是独立页面，而是文章库、图文库左侧的目录树，整理和写作在同一个地方完成。

## 三、首页

首页没有大标题和介绍文字，直接展示内容，按“文字一栏、画面一栏”分层：

1. 左栏是文章：最新一篇（置顶优先）标题放大并带三行摘要，下面再列五篇，每篇是仓库、日期、标题和两行摘要，最后是“全部文章”入口。
2. 右栏是画面：最新一组图文（悬停时自动翻看组内照片），下面是信息源泉的小圆球卡片，圆球可以直接拖动，点标题进入信息源泉页。
3. 再往下是“图文”和“作品”两排，各四张卡片，右上角是“全部”入口。

首页只负责发现和跳转，正常滚动，不劫持滚轮。

## 四、文章浏览

文章页左侧是仓库树，任何层级的仓库一次点击即可到达，计数包含子仓库；右侧默认展示全部文章，按年份分组、置顶优先。每篇文章是一行：左侧月日，中间是仓库、标题和两行摘要；只有设置了封面的文章才在行尾显示封面缩略图，没有封面不会自动生成图片。选中某个仓库时展示它及子仓库中的全部文章，顶部给出面包屑、仓库说明和子仓库快捷入口。窄屏下仓库树收进“仓库”按钮。旧的 `/blog?repository=ID` 链接继续有效。

文章详情为 720px 阅读栏：面包屑、标题、摘要、日期、阅读时长、阅读量、标签，有封面时在标题下方展示封面，正文支持代码高亮（带复制按钮）、表格横向滚动、KaTeX 公式；宽屏右侧有随滚动高亮的目录（文章含两个以上二、三级标题时出现），顶部有阅读进度条，文末是同仓库的上一篇 / 下一篇。外链在新标签打开。

## 五、图文浏览

图文页为照片网格（竖版卡片，悬停时翻看组内照片，角标显示张数），可按图文仓库筛选。详情页左侧为大图与缩略图条（支持方向键切换），右侧为标题、正文、话题、点赞与复制链接。

## 六、信息源泉

信息源泉收录站点主人常逛的网站。每个网站是一个圆球，越常去圆越大；圆球用网站品牌色向暖灰收敛后的低饱和颜色，哑光渐变加细颗粒质感。打开页面时圆球从上方落下堆在一起，可以拖动、甩出去，也可以点“摇一摇”重新洒落。鼠标停在圆球上显示名称、分类、一句话介绍和域名，点击直接在新标签打开；触屏上先点一下看介绍，再点“打开”。顶部的分类标签会把其他分类的圆球淡化；也可以切到“列表”按分类查看，键盘和读屏软件同样可用。

后台“信息源泉”页顶部是实时预览，下方是网站列表：可以添加、编辑、删除，或一键在前台隐藏。每个网站填写名称、网址、分类、一句话介绍、常去程度（偶尔 / 有时 / 常看 / 很常 / 每天，决定圆球大小）、颜色（默认按分类自动配色）和可选的图标链接。首次升级会预置 LinuxDo、AIHOT、北邮人论坛、小红书、抖音、哔哩哔哩。

## 七、站点风格

前台参考 Codrops 的内容网格：浅灰白底、黑色文字和一个蓝色强调色，西文用 Inter，中文用系统字体。页面不放装饰性的大标题和说明文字，由照片、作品和文章本身撑起画面；卡片为 14px 圆角，悬停时图片轻微放大、标题变为强调色。作品卡片使用按作品自动分配的浅色底。前台支持深色模式，跟随系统或手动切换；后台界面使用独立的样式。

## 八、关于与简历

关于页先展示个人介绍（与作品集首页共用，在后台“作品集 → 编辑个人介绍”维护），再展示简历档案和其他平台账号。简历规则不变：前台只显示已发布版本，当前版本居中，可高清阅读和下载 PDF。

## 九、后台：内容库（文章 / 图文）

内容库是三栏工作区：

- 左栏仓库树：顶部固定“全部”“未归档”两个视图，下面是仓库树。点文件夹图标旁的“+”或树顶部按钮直接在树里输入名称新建；双击重命名；右键或“⋯”菜单可新建子仓库、编辑名称与说明、移动到…、删除。拖动仓库到另一个仓库上即放入其中，拖到上下边缘即调整顺序。
- 右栏列表：当前位置的面包屑、标题与说明（点击即可编辑），搜索（`/` 聚焦）、状态筛选（全部 / 已发布 / 草稿，带数量）、排序（最近更新 / 浏览最多 / 标题）、选中仓库时可切换是否包含子仓库。每行显示标题、草稿 / 置顶 / 私密标记、所在仓库路径、更新时间和阅读量；行尾菜单提供编辑、查看页面、复制链接、移动到…、发布或撤回、置顶、设为私密、删除。
- 归档与批量：把一篇或多篇文章拖到左侧仓库（或“未归档”）即完成归档；勾选多行（支持 Shift 连选）后出现批量栏，可批量移动、发布、转为草稿、删除。
- 在某个仓库里点“写文章”，新文章默认归入该仓库；从编辑器返回时回到原来的筛选位置。

删除仓库时，空仓库直接删除；非空仓库会提示其中的内容和子仓库将上移一级（顶层仓库的内容变为未归档），内容本身不会被删除。

## 十、后台：编辑器

文章编辑器是一页居中的文档，后台侧栏自动收起为图标栏，写作时只看到内容本身。

- 实时渲染：正文像 Typora 一样边写边呈现，标题、加粗、链接、图片、列表、待办、引用、代码块、表格、公式都直接显示成排版后的样子；光标移进某一处时才露出那一处的 Markdown 符号，移开后恢复。字号和间距与前台文章页一致。保存的内容仍是原始 Markdown，不会改写已有文章的格式。顶栏的 `</>` 按钮或 Ctrl+/ 切换到源码模式。
- 插入：在空行输入 `/` 弹出菜单，可插入标题、列表、待办、引用、代码块、表格、公式、分割线和图片；选中文字时上方出现小工具条（加粗、斜体、删除线、代码、链接、标题、引用）。快捷键 Ctrl+B / I / E / K、Ctrl+1/2/3；列表回车自动续写，兼容中文输入法；粘贴或拖入图片自动上传并插入；选中文字后粘贴网址自动变为链接。
- 文章信息：标题下方三行不带边框的属性——仓库（点击从目录树中选择）、标签、摘要；封面在标题上方，悬停时出现“添加封面”。链接、发布时间、置顶、私密这类不常改的设置收在顶栏的“发布设置”弹层里。
- 保存：草稿在停止输入约 2 秒后自动保存；已发布文章修改后点“更新”或 Ctrl+S 才生效，避免半成品上线。所有未保存的内容同时备份在本机浏览器，意外关闭后再次打开会提示恢复。
- 发布：草稿显示“保存 / 发布”，已发布文章显示“更新”，“撤回为草稿”和“删除”在更多菜单中。右下角显示字数和预计阅读时长。

图文编辑器结构相同：标题、仓库与话题属性、图片墙（多选上传、粘贴、拖入、拖动排序，第一张为封面）和正文；置顶和“通过链接添加图片”在“图文设置”弹层里。

## 十一、内容规则

- 文章和图文都有草稿与已发布两种状态，草稿只在后台可见；私密文章发布后也只在后台可见。
- 发布时间：草稿首次发布时记为发布当时，除非在设置面板中手动指定。浏览和点赞不会改变“最近更新”时间。
- 链接：首次发布前，文章链接跟随标题自动生成；发布后保持不变，手动修改时如与其他文章重复会提示。
- 阅读时长按约每分钟 400 个汉字或 200 个英文单词估算。
- 仓库可以无限嵌套，但不能放入自身或其子仓库；前台只显示自身或子仓库中有公开内容的仓库。
- 上传的图片保存为 `/uploads/…` 相对地址，更换域名后内容依然可用。

## 十二、总览

总览只回答“接下来做什么”：快捷入口（写文章、发图文、添加作品）、核心数字（文章、图文、累计阅读、已发布）、继续编辑的草稿、待整理事项（未归档文章、缺少摘要的文章、座右铭数量）、最近发布和阅读最多。

## 十三、设计原则

访客路径：首页发现 → 按主题或时间浏览 → 阅读 → 继续阅读同仓库内容。每个页面先给最少的信息，细节放到下一层（标签页、折叠、悬停、弹层），由访客自己决定展开什么。站点主人路径：总览判断 → 内容库定位 → 编辑器写作 → 返回原位置。整理动作（新建、重命名、移动、归档）都在内容库里就地完成，不跳页面；所有破坏性操作都有确认，并尽量提供“保留内容”的默认选择。
