# 产品范围与功能边界

## 1. 产品定位

PanOS 是一个面向个人品牌展示和内容沉淀的全栈网站系统，包含前台展示和后台管理两套体验。

前台面向公开访客，承担个人形象展示、内容浏览、简历查看与联系转化。后台面向站点管理员，承担内容创作、媒体管理、简历维护、站点配置和基础数据统计。

## 2. 用户角色

| 角色 | 目标 | 主要入口 |
| --- | --- | --- |
| 访客 | 浏览首页、文章、图文笔记、简历，复制联系方式或下载简历 | 前台网站 |
| 站点管理员 | 登录后台，发布内容，维护简历，管理媒体和站点配置 | `/admin` |
| 未来协作者 | 参与内容编辑或审核 | 预留，不进入 MVP |

MVP 只实现单管理员模式。数据层保留 `role` 字段和操作日志，后续可扩展为多角色权限。

## 3. 功能模块总览

| 模块 | 前台能力 | 后台能力 | MVP 优先级 |
| --- | --- | --- | --- |
| Landing Page | 沉浸式首页、导航、内容预览、简历预览、3D Hero | 首页配置、推荐内容配置 | P2 |
| 博客文章 | 列表、搜索、分类标签、详情、归档、阅读体验 | Markdown 编辑、草稿、发布、分类标签、统计 | P0 |
| 图文笔记 | 瀑布流、多图轮播、话题筛选、点赞收藏展示 | 多图上传、排序、上下架、置顶、统计 | P1 |
| 个人简历 | 信息展示、时间轴、技能、项目、PDF 导出 | 分区编辑、排序、版式配置、导出配置 | P1 |
| 后台管理 | 无 | 登录鉴权、控制台、内容管理、系统设置 | P0 |
| 媒体资源库 | 图片通过 CDN/对象存储展示 | 上传、裁剪、压缩、缩略图、搜索、批量删除 | P0 |
| 数据统计 | 阅读量、浏览量、热门内容 | 仪表盘、趋势、登录日志 | P2 |

## 4. MVP 范围

MVP 目标是跑通“登录后台、上传媒体、创建内容、发布内容、前台展示”的完整闭环。

### 必须实现

- 管理员登录、退出、Token 刷新、登录日志。
- 媒体上传、图片元信息保存、缩略图生成、WebP 变体生成。
- 博客文章 CRUD、Markdown 编辑、分类标签、草稿/发布/回收站。
- 博客前台列表、详情、分类页、标签页。
- 图文笔记 CRUD、多图排序、前台瀑布流和详情页。
- 简历结构化编辑和前台展示。
- 站点基础配置：标题、描述、SEO、社交链接、备案信息。

### 暂缓实现

- 第三方评论系统接入。
- 多管理员角色权限。
- 复杂 A/B 测试或推荐算法。
- 访客真实账号系统。
- 在线支付、订阅、私域会员。
- 后台富文本编辑器高级协同编辑。

## 5. 内容状态定义

| 状态 | 说明 | 前台可见 |
| --- | --- | --- |
| `draft` | 草稿，仅后台可见 | 否 |
| `scheduled` | 已设置未来发布时间 | 到时间后可见 |
| `published` | 已发布 | 是 |
| `private` | 私密内容，需要管理权限预览 | 否 |
| `archived` | 归档保留，不推荐展示 | 可按配置决定 |
| `trashed` | 回收站，等待删除 | 否 |

博客和图文笔记共享上述状态。简历采用 `active` 布尔值控制当前展示版本。

## 8. 产品验收原则

每个模块都需要满足四类验收：

- 内容闭环：后台可创建、编辑、发布，前台能正确展示。
- 状态闭环：草稿、发布、下架、删除状态稳定且可恢复。
- 媒体闭环：图片上传、压缩、引用、删除不产生孤儿资源。
- 体验闭环：移动端、暗色模式、加载态、空状态、错误态都可用。
